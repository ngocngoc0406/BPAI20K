# Software changelog (campaign-relevant)

Every change to `src/`, `pages/` or `ui/` during a data-collection campaign changes `software_sha256` in session provenance
and must be listed here. A change to the model, the features, the thresholds, the alert logic or the calibration is not allowed
during a campaign.
